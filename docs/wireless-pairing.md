# Flit 无线调试与通知配对

应用内入口：设备连接 → **通知配对**，或 **无线配对指南**。教程内容随 App 提供，无需联网加载网页；只有“参考：Shizuku 使用指南”会打开外部网页。

## 准备

- Android 11 或以上，手机连接 Wi-Fi；开启开发者选项、USB 调试与无线调试。
- 安装 Flit 开发环境中的 Android Platform Tools（ADB）。
- 允许 Flit 发布通知；若通知设置里已有“无线调试配对”类别，也要开启该类别。
- 指南会检查系统版本、通知总开关和配对通知类别。从系统设置返回后自动重新检查。阅读指南本身不会启动配对，点击“开始配对”才会启动通知服务。

## 四步完成配对

1. 在指南点击“开始配对”。Flit 先启动通知服务，再打开开发者选项。
2. 打开无线调试开关，然后点击“无线调试”的文字进入详情，选择“使用配对码配对设备”。只打开右侧开关不够。保留显示 6 位代码的系统窗口。
3. 下拉并展开 Flit 的通知，点击“输入配对码”，输入系统窗口里的 6 位码并发送。不要切回 Flit 输入：切换应用可能关闭系统配对窗口。找到配对端口后，通知才会出现输入按钮。
4. 通知提示配对成功后返回 Flit，自动尝试连接本机。以后已配对时直接“扫描并连接”；重新开启无线调试后，连接端口可能改变。

## 小米 / POCO：原生通知样式

Shizuku 的应用内教程和网页指南都指出：部分 MIUI 的通知样式会影响通知内回复，可能没有输入框，或者点击“输入配对码”立即失败。

在系统设置 → **通知管理** → **通知显示设置**，把通知样式改为 **原生样式**，再重新开始配对。Redmi、HyperOS 和其他系统版本的路径或名称可能不同；如果提供“Android”或“原生”通知样式，可以尝试切换。这不是所有机型都必须修改的设置。

Flit 能检查通知是否被禁用，但 Android 没有通用接口供应用读取或切换厂商的通知样式，需手动操作。没有此选项时，可用分屏保留系统配对窗口，在 Flit 的“手动连接 / 其他设备”输入配对端口和配对码。

## 一直搜索端口

配对端口只在“使用配对码配对设备”窗口打开时广播。先确认 Wi-Fi、无线调试和这个窗口都处于开启状态。

部分系统会在 Flit 不可见时限制它访问本地网络，即使正在运行前台通知服务。请允许 Flit 后台运行，并在系统联网管理中允许 Wi-Fi / 本地网络访问（如果系统提供这类设置）。指南提供“允许后台运行”入口；厂商额外的限制需在系统中手动调整。

仍找不到时，可重新开关无线调试，再重新配对。Flit 最多搜索 3 分钟，超时后需重新开始；也可用分屏手动配对，或改用电脑 USB 激活。

## 配对成功但连接失败

**配对端口与连接端口不同。** 手动连接使用无线调试主页中的端口，不使用配对码窗口的端口。配对记录只表示完成过配对，不代表手机现在在线。

回设备页点击“扫描并连接”；扫描仍失败时，可手动填写连接端口，或改用电脑 USB 激活。
